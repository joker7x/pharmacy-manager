# صيدليتي 💊

نظام إدارة صيدلية متكامل، حديث، ويعمل أوفلاين أولًا باللغة العربية (React + Vite + TypeScript + Tailwind CSS).

## المميزات الرئيسية

- **لوحة تحكم ذكية (Dashboard)**: مؤشرات مالية لمبيعات اليوم، صافي الأرباح، المصروفات، وتنبيهات فورية بالنواقص الحرجة وتواريخ الصلاحية.
- **شاشة الكاشير والبيع السريع (POS)**: بحث فوري بالأدوية والباركود، سلة مشتريات ديناميكية، دعم الدفع النقدي وحساب الباقي وفودافون كاش، مع إمكانية طباعة الإيصال الحراري.
- **إدارة المخزون والأدوية (Inventory)**: جرد كامل للأصناف، كميات المخزون، حدود إعادة الطلب، تواريخ الصلاحية، إضافة وتعديل وحذف الأصناف.
- **إدارة النواقص وطلبيات الموردين (Shortages & Reorders)**: تتبع الأصناف المطلوبة وقيد التوريد، وتحويلها بضغطة زر واحدة إلى رصيد المخزن فور الاستلام.
- **الورديات وخزينة الدرج (Shifts & Cash Drawer)**: بدء الشيفتات، تتبع الرصيد الافتتاحي، وحساب المبلغ المتوقع فعليًا في الدرج بناءً على المبيعات والمصروفات، مع جرد دقيق للعجز أو الزيادة.
- **الآجل والعملاء (Customer Debts)**: تسجيل ديون العملاء وجدولة السداد والدفعات الجزئية.
- **المصروفات اليومية (Expenses)**: قيد المصروفات التشغيلية والتوريد وخصمها من خزينة الوردية الجارية.
- **دليل الموردين (Suppliers)**: قائمة شركات التوزيع ومندوبي الأدوية مع إمكانية الاتصال المباشر.
- **التقارير المالية والتحليلات (Reports)**: إحصائيات المبيعات، أكثر الأدوية مبيعًا، وتوزيع طرق الدفع.
- **النسخ الاحتياطي (Backup & Restore)**: تصدير واسترجاع قاعدة البيانات بصيغة JSON محليًا.

## التشغيل والتطوير

```bash
npm install
npm run dev
```

يعمل خادم التطوير على المنفذ `3000` (`http://localhost:3000`).
