# إشعارات الهاتف عبر Expo

اعتمد التكامل على خدمة Expo لإرسال الإشعارات من الخادم، بعد أن يمنح المستخدم الإذن ويسجل التطبيق رمز `ExpoPushToken` المرتبط بمشروع التطبيق. يخزن التطبيق الرمز للجهاز فقط مع بيانات تشغيلية محدودة: اسم الجهاز، المنصة، الطراز، إصدار النظام وإصدار التطبيق. لا تُعرض رموز الإشعارات داخل لوحة المسؤول.

يُنشأ إشعار داخلي دائمًا كسجل داخل التطبيق، ثم يُرسل Push فقط إلى الأجهزة المفعلة. يسجل الخادم حالة قبول أو فشل الطلب، ويعطل الجهاز تلقائيًا عند استلام خطأ `DeviceNotRegistered`.

## المتطلبات قبل الاختبار الفعلي

- يلزم جهاز فعلي أو محاكي Android يدعم Google Play؛ لا تعمل إشعارات الهاتف من معاينة الويب.
- يلزم بناء تطوير أو إصدار تطبيق مهيأ للإشعارات ومرتبط بمشروع Expo.
- يلزم إعداد بيانات FCM V1 لنظام Android، وإعادة بناء التطبيق بعد ربطها.

## المصادر

1. [Expo Push Notifications Setup](https://docs.expo.dev/push-notifications/push-notifications-setup/) — إذن المستخدم، `ExpoPushToken`، تهيئة المشروع وFCM.
2. [Expo Push Service: Sending Notifications](https://docs.expo.dev/push-notifications/sending-notifications/) — إرسال HTTP، دفعات حتى 100 رسالة، التذاكر والإيصالات وتعطيل الأجهزة غير المسجلة.
