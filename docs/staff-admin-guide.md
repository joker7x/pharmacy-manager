# إدارة أفراد الصيدلية

## التشغيل الأول

عند فتح التطبيق بعد هذا التحديث ستظهر شاشة **إعداد حساب مسؤول الصيدلية** إذا لم يوجد أي حساب تشغيل. يُنشأ هذا الحساب مرة واحدة فقط، ثم يصبح إنشاء باقي الحسابات محصورًا في لوحة **أفراد الصيدلية**.

## الأدوار الافتراضية

| الدور | الاستخدام الافتراضي |
| --- | --- |
| مالك الصيدلية | كل الصلاحيات، وإدارة الأفراد والإشعارات وسجل النشاط. |
| صيدلي | البيع والمخزون والطلبيات والمصروفات والشيفتات والتقارير. |
| كاشير | نقطة البيع، عرض المخزون، وإدارة الشيفت. |
| مراجعة فقط | عرض المخزون والتقارير دون تعديل. |

يمكن للمسؤول فتح بطاقة الفرد وتعديل صلاحياته الدقيقة، تغيير الدور، تجميد الحساب لمدة 24 ساعة، تعطيله، أو إعادة تعيين كلمة المرور.

## الخصوصية وسجل النشاط

تُسجَّل عمليات الدخول والخروج، إنشاء الحسابات وتعديلها، الرسائل الإدارية، والعمليات التشغيلية المدعومة مثل البيع وتغيير كمية المخزون وحذف صنف. يربط السجل بالحساب ووقت العملية واسم الجهاز والمنصة. يُخفى الجزء الأخير من عنوان IPv4 قبل تخزينه، ولا يجمع التطبيق الموقع الجغرافي أو ملفات الجهاز أو بيانات لا تلزم للتشغيل.

## الإشعارات

من تبويب **إشعار** يستطيع المسؤول إرسال رسالة لكل العاملين أو لدور محدد أو لفرد محدد. تصل الرسالة إلى صندوق الإشعارات داخل التطبيق عند فتحه أو أثناء استخدامه، ولا تحتاج إذن إشعارات الهاتف في هذه المرحلة.
